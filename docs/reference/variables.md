# Variable glossary

Every quantity in the library carries a record: a grammar name, a
human-readable name, a unit, bounds where it has them, and a description.
The code reads that record to build design spaces and uncertain spaces;
this page reads the same record, so the two cannot drift apart.

Everything below is generated. If a variable is renamed, given a unit, or
gains a bound, this page changes with it and nothing needs editing.
